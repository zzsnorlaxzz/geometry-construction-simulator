# 기하 작도 시뮬레이터 · 수업용

점·선분·직선·컴퍼스 등의 도구를 사용하는 기하 작도 프로그램입니다. 조건 제시와 작도 작업 영역을 수업에 맞게 구성한 버전입니다.

**[프로그램 실행](https://zzsnorlaxzz.github.io/geometry-construction-simulator/)**

## 파일

- `index.html`: 프로그램 전체. 브라우저에서 열어 실행할 수 있습니다.
